## Global Notes

- Each main flow lasts about four seconds
- Entry and exit are consistent across all scenes: subtle fade in, subtle fade out only
- Every cursor click has a slight scale up and down to show a click
- On exit of each scene, the cursor floats straight to the next nav item (no detour)
- Cursor X/Y positions are approximated from the frames

**Timing:** beat timing does not need to be uniform across scenes. Tune per scene in the build.
